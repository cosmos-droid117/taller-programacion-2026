# Cuadrícula de Coordenadas

## Descripción

Programa realizado en Python que permite crear una cuadrícula de tamaño N × M, con un mínimo de 8 × 8. Cada posición comienza con un círculo vacío (`○`) y el usuario puede ingresar coordenadas para marcar los puntos con un círculo relleno (`●`).

## Funciones

- Crear la cuadrícula.
- Ingresar y marcar varios puntos.
- Validar las coordenadas.
- Mostrar los puntos ingresados.
- Reiniciar la matriz.
- Salir del programa.

## Tecnologías

- Python
- GitHub

## Requerimientos funcionales

La aplicación cumple con los siguientes requisitos:

- **RF01.** Mostrar una cuadrícula de mínimo 8 × 8 círculos.
- **RF02.** Asociar cada círculo de la cuadrícula con una coordenada (X, Y).
- **RF03.** Iniciar la cuadrícula con todos los círculos vacíos (`○`).
- **RF04.** Permitir al usuario ingresar coordenadas mediante la consola.
- **RF05.** Cambiar a círculo relleno (`●`) la posición correspondiente a una coordenada válida.
- **RF06.** Validar que las coordenadas ingresadas estén dentro de los límites de la cuadrícula.
- **RF07.** Mostrar un mensaje de error cuando se ingrese una coordenada inválida.
- **RF08.** Permitir al usuario ingresar y marcar varias coordenadas.
- **RF09.** Permitir reiniciar la cuadrícula y devolver todos los círculos a su estado inicial.
- **RF10.** Mostrar las coordenadas ingresadas por el usuario.
